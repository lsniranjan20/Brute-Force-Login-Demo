### Brute Force Login Demo 

This is a *Python-based brute force login demo project* created for *educational and learning purposes only*.

The project demonstrates how brute-force attacks work so that developers and cybersecurity learners can understand, test, and improve login security.

---

##  Features
- Python-based implementation
- Demonstrates brute force attack logic
- Easy to understand code
- Tested on Kali Linux

---

##  Technologies Used
- Python 3
- Kali Linux
- Git & GitHub

---

##  Project Files
- login.py – Simulates login authentication
- brute.py – Performs brute force attack logic

---

## How to Run (Kali Linux)

```bash
cd brute_force_demo
python3 login.py
python3 brute.py
